# Big Bang Origin

**Design Style**: Interactive, Particle System, Dark Theme
**Core Technologies**: React, Next.js, Tailwind CSS, Canvas/Three.js

## Key Features
- **Cosmic Animation**: Interactive particle simulation resembling the origin of the universe.
- **Dynamic Scroll**: Time-lapsed scroll effects.

## The Prompt
> "Build a cosmic, interactive landing page called Big Bang Origin. Use a dark theme with deep space blacks. The main visual should be an interactive canvas or Three.js particle simulation that expands as the user scrolls, simulating the origin of the universe. Use a sleek, modern sans-serif font for the typography."
