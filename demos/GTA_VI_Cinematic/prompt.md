# GTA VI Cinematic Landing Page

**Design Style**: Vice City Aesthetic, Neon Lights, Cinematic
**Core Technologies**: React, Next.js, Tailwind CSS

## Key Features
- **Vice City Vibes**: Pink and cyan neon accents with a dark sunset backdrop.
- **Video Background**: Full-screen cinematic trailer loops.

## The Prompt
> "Create a high-energy, cinematic landing page for GTA VI. The design should scream 'Vice City' with a dark sunset aesthetic, utilizing neon pinks and cyan blues. Incorporate a full-screen looping cinematic video background. Use bold, stylized fonts for the headings."
